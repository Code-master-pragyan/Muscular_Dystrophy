
# Figures

This directory stores research figures generated from the Dataset B (FSHD ultrasound) experiments.

## Recommended Contents

- CNN training and validation curves.
- Image-level and group-level confusion matrices.
- Class-wise performance visualizations.
- Radiomics feature-distribution plots.
- Explainability figures.
- Research methodology and workflow diagrams.

## File Naming Convention

Use descriptive filenames:

- `cnn_training_curves.png`
- `cnn_group_confusion_matrix.png`
- `radiomics_group_confusion_matrix.png`
- `hybrid_feature_selection_summary.png`

## Reproducibility

For every figure, document:

1. The script or notebook that generated it.
2. Dataset and partition used.
3. Evaluation level (image-level or group-level).
4. Metric definition and class ordering.

Do not present synthetic or illustrative plots as experimental results. All research figures must correspond to verified project outputs.
